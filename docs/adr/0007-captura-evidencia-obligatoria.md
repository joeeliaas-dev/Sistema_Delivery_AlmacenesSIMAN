# ADR 0007 · Captura de evidencia obligatoria por entrega

Estado: Aceptada · 1 de noviembre de 2026

Contexto La operación de logística exige que una entrega no sea simplemente un botón de "marcar como hecha"; debe quedar documentada objetivamente para respaldar al conductor en caso de reclamos.

Decisión El sistema requerirá obligatoriamente capturar una fotografía, una firma y una descripción cada vez que se confirme una entrega.

Consecuencias

Convierte la operación en un proceso verificable, creando trazabilidad y reduciendo disputas.

Fortalece enormemente la confiabilidad general del sistema.

Añade fricción y tiempo extra al flujo de trabajo del motorista en la calle.

Aumenta el consumo de cuota de almacenamiento en la nube para alojar las firmas y fotografías.
