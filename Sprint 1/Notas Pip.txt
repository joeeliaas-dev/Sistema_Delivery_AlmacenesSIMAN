Activación del entorno con Python

1. Siempre borrar el entorno virtual antiguo: 

rm -rf .venv

2. Instalar o recargar soporte para Linux

sudo apt update && sudo apt install python3-venv python3-pip -y

3. Creación y activación del entorno

python3 -m venv .venv
source .venv/bin/activate

4. Instalación de dependencias y correr el entorno

pip install -r requirements.txt
python app.py
